## 关于EazyMake的一些说明

### 为什么要写EazyMake

c/cpp项目构建系统是必不可少的一部分,目前最主流的解决方案当然是CMake,
但是CMake的SDL导致其相对来说是比较难以学习和使用。
所以我写了EazyMake,致力于打造一个便于使用并且有一定工程价值的构建工具。

### 为什么仓库选择基于git的去中心化仓库

自然去中心化仓库有许多优点,但是对于我来说维护一个完全中心化的仓库的成本太高了。
